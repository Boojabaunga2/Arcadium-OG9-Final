ARCADIUM OG9 — SCOREBOARD BETA

Open index.html in Chrome or an Android browser that permits local file access. All nine games are in games/. Keep the folder intact.

Select + PLAYER to add profiles. Play a game; its numeric score is observed every half-second and the highest observed value is saved locally. Home Run Derby records home runs rather than points. Scores tab shows top ten local personal bests for each game; Monthly shows this device's records for the current UTC month. Export regularly to JSON. Import replaces current records.

IMPORTANT: These are unverified local records, NOT official cross-device leaderboards. Scores persist only if the browser allows localStorage for local files and does not clear its data. The games may have varying scoring conventions and end-game conditions; further playtesting needed.

INSTALLATION: This is an offline browser bundle, NOT an APK. To use on a square Android Mini Vibe, transfer the extracted folder, open index.html in a browser, and test physical D-pad/buttons. For a reliable kiosk APK, WebView file permissions and hardware key mappings must be validated on the actual device.
